# 设计规范

沿用当前华为云演示的简洁技术发布风格：大标题、明确层次、大块留白、稳定的对齐、有限的红色强调。避免通篇红色背景、多种强调色、复杂渐变和密集文字。

| 部位 | 默认值 | 规则 |
| --- | --- | --- |
| 画布 | 1600×900 | 所有设备缩放画布，手机也保持 16:9 |
| 页边距 | 左右 84px | 页头、标题、内容和页脚统一对齐 |
| 页头 | 104px 高 | 原比例 Huawei Logo + 最多 5 个章节链接 |
| 标题 | 中文 44px / 英文 40px | 先调整措辞；允许合理换行，检查下方内容位置 |
| 副标题 | 中文 23px / 英文 21px | 补充主标题，不重复主标题 |
| 正文 | 常用 20–29px | 价格、关键能力不缩成脚注；不整体缩小 CSS 来塞内容 |
| 页脚 | 距底 24px、高 38px | 内容与页脚顶部至少 8px 画布距离 |
| 品牌红 | #c7000b | 用于关键数字、当前章节、少量边框和流程高亮 |
| 正文 / 次要文字 | #222326 / #777b82 | 正文清晰；说明适度灰色 |
| 背景 / 线条 | #fff / #e8e8ec | 卡片使用 #f7f7f9、局部 #fcf0f0 |

## Logo 与图片

- 基础包包含 Huawei Logo PNG 和山景封面底图，均来自用户当前演示仓库。保留透明区域、宽高比和足够留白。
- 新产品图标和业务场景图由当前项目提供；通用包只保存 Huawei Logo 与封面背景。
- 产品图片用 `object-fit:contain`；背景图片才使用 cover 或裁切。
- 架构图先用 HTML/CSS/SVG，节点和连线要有语义。SVG 文字不会自动换行，应检查英文宽度，必要时分行或扩大节点。
- 不能为了方便为其他产品继续使用旧产品图、QR 或业务图。新图片由用户素材或产品官方内容获得。

## 排版与动效

- 用结果组织内容，例如“任务 → 执行 → 结果”，而不是一页堆全部功能。
- 卡片保持同一层次；架构保留层级关系；比较用一致维度；定价列明确货币、周期、容量口径、超额规则。如果有缓存输入价格，放在输入价格右侧独立列，字号与其他价格一致。
- 中文紧凑结构与英文长词长度不同。英文页面检查卡片内部、容器底部、标题、章节和页脚；`minmax(0,1fr)` / `min-width:0` 防止长词撑开列。
- 流程动效每步默认 2.4 秒，只高亮当前节点，其他节点始终可读。淡入默认约 0.3 秒。
- 文本较多时使用轻量动效或静态内容，允许手动场景切换。不要用自动场景轮换打断阅读。
- 打印、缩略图和减少动态效果模式显示完整信息。纯流程示意应明确为示意，不伪装成真实请求执行。
